Introducción a la Programación orientada a PLC

Actividad 1 — Algoritmo

Actividad grupal: Ordenar tarjetas impresas.

  • Se entregarán tarjetas con pasos de un proceso.
  • El grupo deberá ordenar las tarjetas correctamente.
  • Identificar si existe alguna tarjeta incorrecta.
  • Explicar por qué eligieron ese orden.

Objetivo: Comprender que un algoritmo es una secuencia de pasos ordenados.

Actividad 2 — Programación con función print()

Resolver las siguientes consignas utilizando Python y la función print().

  1. Mostrar en pantalla los pasos para encender una máquina.
  2. Mostrar el proceso de llenado de un tanque de agua.
  3. Mostrar qué ocurre cuando una puerta automática se abre y se cierra.
  4. Mostrar el recorrido de una caja en una cinta transportadora.
  5. Mostrar las luces de un semáforo en orden.

Objetivo: Comprender que un programa es una secuencia de instrucciones.

Actividad 3 — Entrada de Datos

Resolver las siguientes consignas utilizando Python y la función input().

  1. Ingresar un número que represente el estado de un pulsador y mostrarlo en pantalla.
  2. Ingresar una temperatura y mostrarla en pantalla.
  3. Ingresar la cantidad de piezas producidas y mostrarla.
  4. Ingresar el nivel de un tanque y mostrarlo.
  5. Ingresar la velocidad de una máquina y mostrarla.

Objetivo: Comprender cómo un programa puede recibir datos del usuario.

Actividad 4 — Operadores en Python

Resolver los siguientes ejercicios utilizando variables, operadores matemáticos y operadores de comparación.

Ejercicio 1 — Suma de dos números

Crear dos variables con valores numéricos y mostrar en pantalla el resultado de la suma.

Ejercicio 2 — Operaciones matemáticas básicas

Crear dos variables numéricas y mostrar:

  • La suma
  • La resta
  • La multiplicación
  • La división

Ejercicio 3 — Comparación de números

Crear dos variables con números distintos y mostrar en pantalla:

  • Si el primero es mayor que el segundo
  • Si son iguales
  • Si son diferentes

Ejercicio 4 — Edad

Crear una variable llamada edad con un valor numérico y mostrar:

  • Si la edad es mayor que 17
  • Si la edad es igual a 18
  • Si la edad es diferente de 21

Ejercicio 5 — Precios

Crear dos variables con precios de productos y mostrar:

  • El total de la compra
  • La diferencia entre los precios
  • Si el primer precio es mayor que el segundo

Objetivo: Comprender el uso de operadores matemáticos y operadores de comparación en Python.

Actividad 5 — Toma de decisiones (if)

Resolver los siguientes ejercicios utilizando estructuras condicionales.

Ejercicio 1 — Sensor de temperatura

Una máquina tiene un sensor de temperatura. Si la temperatura es mayor o igual a 70 grados, mostrar el mensaje: “Alarma de temperatura”.

Ejercicio 2 — Pulsador de arranque

Un pulsador puede tener dos estados: 1 → Encendido 0 → Apagado Si el pulsador está en 1, mostrar “Motor encendido”. Si no, mostrar “Motor apagado”.

Ejercicio 3 — Nivel de tanque

Un sensor mide el nivel de un tanque. Si el nivel es mayor a 80, mostrar “Tanque lleno”. Si no, mostrar “Tanque en proceso de llenado”.

Ejercicio 4 — Velocidad de motor

Un motor puede funcionar en tres estados según su velocidad: Mayor o igual a 100 → Alta velocidad Mayor o igual a 50 → Velocidad media Menor a 50 → Velocidad baja Mostrar el estado correspondiente.

Ejercicio 5 — Sistema de alarma industrial

Una máquina tiene un sensor de temperatura. Si la temperatura es mayor a 70 grados, mostrar “Alarma activada”. Si no, mostrar “Sistema normal”.

Objetivo: Comprender la toma de decisiones en programas mediante estructuras condicionales.

Actividad 6 — Bucles (while y for)

Resolver los siguientes ejercicios utilizando estructuras repetitivas.

Ejercicio 1 — Conteo de piezas

Simular una máquina que produce 5 piezas. Mostrar en pantalla el número de cada pieza utilizando un bucle.

Ejercicio 2 — Luces de señalización

Simular el encendido de 3 luces de señalización mostrando cada estado en pantalla.

Ejercicio 3 — Llenado de tanque

Simular el llenado de un tanque desde 0 hasta 100 aumentando de 10 en 10 utilizando un bucle while.

Ejercicio 4 — Control de temperatura

Simular el aumento de temperatura de una máquina desde 30 hasta 60 grados aumentando de 5 en 5.

Ejercicio 5 — Producción de lotes

Simular la producción de 4 lotes mostrando en pantalla el número de lote utilizando un bucle for.

Objetivo: Comprender el uso de bucles para repetir procesos en programas.
